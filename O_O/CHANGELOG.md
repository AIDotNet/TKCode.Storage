# O_O 更新日志

版本号为 主版本.次版本.构建号（按数字比较）。发布时 CI 从本文件取出对应版本的一节作为 GitHub Release 和 O_O 服务的版本说明。

## 0.2.2 · 2026-11-10

### 新功能
- **自定义数据目录**（#1）：「控制台 → 关于 → 数据目录 → 更改…」可把插件、插件数据和偏好移到其他文件夹（例如另一块磁盘），O_O 重新启动时把数据复制过去、确认无误后删除旧的；失败时数据留在原处并在「关于」页说明。「恢复默认」移回默认位置。所选文件夹里已有其他文件时，数据放在其中新建的 `O_O` 文件夹。Windows 安装程序首次安装时也可以选择数据目录。`settings.json` 始终留在默认位置（它记录数据目录在哪）。

### 修复
- 待办：在岛上完成或删除任务后，「即将到期」活动立即更新，不再继续显示已完成的任务。

## 0.2.1 · 2026-11-10

### 新功能
- **自动更新**：「关于 → 自动下载并安装更新」（默认打开）。发现新版本后在后台下载，下载好后岛上提示一次，退出 O_O 时自动安装；也可以在「关于」页「立即重启并更新」。macOS 会校验新版本的签名与当前一致才替换；Windows 静默安装；Linux 仍在「关于」页提供下载。
  从 0.2.0 升到 0.2.1 仍需手动下载安装一次，之后的版本都会自动更新。

### 改进
- 插件市场的卡片重新排版：图标、名称和来源在上，按钮在右，描述最多两行（悬停看全文），卡片按窗口宽度等分成列、同一行一样高；不再截断文字。
- 界面组件库 Arc 升级到 1.1.0-preview.1（Avalonia 12.1.5）。

## 0.2.0 · 2026-11-10

岛 2.0：参考苹果的灵动岛重新设计（docs/design/09-island-v2.md）。插件接口升级到 2.0，旧版插件不再能用。

### 岛
- **活动**：岛上显示「正在进行的事」——播放、专注计时、日程即将开始、待办到期、额度告警、未读消息。最多同时显示两个：第一个在岛上，第二个变成岛旁边的小圆泡，点小圆泡可以互换；其余排队。
- **点一下展开**：有活动时点岛打开它的卡片（标题、内容和控制按钮），卡片右上角「主页」进入原来带页签的仪表盘；没有活动时点岛直接打开主页，快捷键总是打开主页。
- **悬停只提示**：指针移到岛上岛会稍微变大，点一下才展开（可在 岛体 → 外观 → 悬停展开 改回旧行为；全屏时的细线仍悬停展开）。
- ⌘ 点击（Windows/Linux 为 Ctrl）打开活动的来源应用；在岛上左右滑动切换活动，向上滑动把当前活动放到最后。
- **提醒**一次一个，重要的先显示；新消息、日程、额度告警都用提醒。
- 空闲时岛两侧显示「环境项」（原来的小项），你的排序、左右和开关设置原样保留。

### 主题
- 主题可以改变岛本身：表面（纯色、渐变、半透明、流动的动态背景）、圆角、每类活动的颜色、形变的弹性、小圆泡的出现方式、吉祥物、提示音和卡片布局。贴着刘海时岛体仍是黑色。
- 新主题「流动极光」；「极光」「玻璃」「黑白」更新了岛的外观。
- 外观页的主题卡片上有用该主题画的小岛；新增「提醒时播放主题的提示音」（默认关闭）。

### 控制台
- 岛体页重新整理为可折叠的「收起时 / 活动 / 主页 / 外观」，右侧是用插件当前内容画出的实时预览，可「在岛上试一下」。
- 新增「活动」设置：调整顺序，每类活动可设为允许、只提醒或关闭，可以置顶一个。
- 插件页改为按类别分组；数据来源插件（如 Claude 用量）显示在它所服务的插件（AI 用量）卡片里；「添加插件」改为可搜索、可按类别筛选的「插件市场」。

### 插件
- 插件接口 2.0：`island.activity`、`island.ambient`、`island.home.page`、`island.alert`；插件需要声明 `"engines": { "island": "^2.0.0" }`。旧接口（`island.page`、`island.chip`、`island.satellite`、`island.activity.create`）已移除。
- 所有官方插件已升级到 0.2.0；从插件目录装过的旧版插件会在启动时自动换成新版本。
- 网易云：在网易云里暂停后岛上立即显示暂停，暂停时仍保留播放按钮。
- AI 用量等数据来源插件会自动启用它所依赖的插件。
- 「让 AI 写插件」的技能已按 2.0 接口更新。

### 已知限制
- 动态背景在用电池时不会自动停下（减少动态效果时是静态的）。

## 0.1.1001 · 2026-11-10

### 新功能
- **通知监听与卫星岛**：插件可在用户授权后接收指定应用（微信、QQ 等）的系统通知和未读角标，并在主岛旁的卫星小岛里显示，图标为消息来源应用的图标。权限按来源授予（`notifications.listen:<来源ID>`），始终需要用户确认；控制台可全局隐藏消息正文。macOS、Windows、Linux 各有对应实现。
- **消息插件 com.o_o.im**：显示来源图标，合并短时间内的连续消息，保留未读胶囊。
- **系统日历**：macOS 读取系统日历，新增 com.o_o.cal.system 插件。
- **开机启动**：控制台新增「系统」页，可设置开机自动启动。
- **更新检查**：启动时和每 24 小时检查新版本（关于 → 自动检查更新），也可手动「检查更新」；有新版本时在岛上提示一次，并在「关于」页提供下载链接，不会自动下载或安装。
- **插件目录**：13 个官方插件改为从插件目录安装（添加插件 → 插件目录），下载经 https 并校验大小和 sha256，自动先安装依赖；目录插件和用户插件一样申请权限，插件抽屉里显示可用更新。清单新增 `requires` 与 `platforms`，不适用于当前系统的插件会被跳过。
- **网易云音乐插件**：岛上的音乐条按真实响度跳动（macOS 14.4+ 通过 CoreAudio 进程 tap，仅输出频段电平），正在播放页带滚动歌词、排行榜和设置。
- **插件 UI**：`ui.spectrum` 频谱条；`ui.grid` 等宽栅格；`ui.arc` 可按名称创建 Arc 控件（含 LineChart、BarChart、DonutChart、Sparkline 图表）。
- **主题与布局**：主题包可用 token 重新着色岛体；插件可提供布局预设（内置「简洁 / 专注 / 工作台」）。
- 新的应用图标。

### 修复
- Windows 安装程序：简体中文语言文件改为在打包时下载（固定为 Inno Setup 6.4.3 的版本），不再依赖编译器目录里自带。
- 点击打开链接：点击的有效窗口从插件收到点击时开始计算，插件繁忙或机器较慢时也能打开被点击的链接。
- 布局预设的校验位置错误，以及频谱控件渲染分支错位的问题。
