# 09 · 岛 2.0：灵动岛状态模型、主题包与插件 API 2.0（草案）

> 状态：已实现（2026-11-10，分支 `o_o-island-v2`，随 0.2.0 发布）。取代 07 的「页面 / 小项 / 活动」三概念和 08（通知）里的卫星岛呈现方式。
>
> 与方案的出入：
> - 动态背景没有用 Lottie / 视频：由宿主内置三种 Skia 着色器预设（aurora、pulse、waves），主题只选预设和颜色（§4）。
> - 用电池时自动降为静态图尚未实现；减少动态效果时已是静态。
> - 小项（chip）改名为环境项（ambient），键名与旧小项相同（`plugin/id[#instance]`），用户的排序与开关、布局预设沿用；
>   环境项也支持 `multiple`（每个账户一个）。
> - 卫星窗口保留，只用作第二个活动的小圆泡；插件不再能直接使用。
> - 目录里装过的 1.x 插件在启动时自动换成目录里的 2.0 版本（`CatalogInstaller.UpgradeStrandedAsync`）。
>
> 已定的三个选择：
> 1. **整体方案**：灵动岛 + 环境层（活动按苹果规则；空闲时保留少量环境项；带页签的仪表盘改为「主页」）。
> 2. **主题深度**：完全自定义（分层配置 + 动态背景、吉祥物、提示音、区域版式模板）。
> 3. **插件过渡**：只支持新模板，插件 API 升到 2.0，旧 API 移除。

## 1. 为什么重做

现在的岛更像「刘海上的仪表盘」：收起时常驻多个小项，展开是带页签的应用。苹果的灵动岛只呈现**正在发生的事**，
平时是一块黑色遮罩。两者的差别（详见讨论记录）归结为四点：

| | 苹果 | O_O 1.x |
| --- | --- | --- |
| 主角 | 有始有终的活动 | 常驻小项 + 页面 |
| 同时显示 | 最多 2 个，优先级仲裁 | 小项、活动、卫星岛三套机制 |
| 内容结构 | 固定区域，App 往里填 | 插件自由绘制 |
| 动画 | 一个形状连续变形 | 面板切换 |

## 2. 状态模型

岛在任一时刻处于下面一种呈现；除「主页」外都由宿主根据活动自动决定。

| 状态 | 条件 | 呈现 |
| --- | --- | --- |
| **空闲** | 没有活动 | 黑色岛；两侧各最多 2 个**环境项**（可全部关掉，即纯黑） |
| **紧凑** | 有 ≥1 个活动 | 优先级最高的活动占据岛：左 = 身份，右 = 状态。环境项让位 |
| **最小** | 有 ≥2 个活动 | 第二个活动变成岛旁的**小圆泡**（从岛的形状里分离出来）；第三个起排队 |
| **展开** | 单击岛（有活动时） | 当前活动的详情卡片，固定区域：左、右、中、底 |
| **提醒** | 活动发出提醒，或一次性通知 | 岛自动短暂展开（或加宽）几秒，然后回到之前的状态 |
| **主页** | 没有活动时单击岛；或快捷键；或展开卡片里的「主页」入口 | 带页签的仪表盘（日历、天气、剪贴板……） |

### 2.1 仲裁

- 活动带 `priority`：`critical`（通话、计时结束）> `high`（会议将开始、用量告警）> `normal`（播放中、专注中）> `passive`。
- 同级按「最近更新」排序；用户可在设置里**固定**一个活动，或把某类活动设为「只提醒」「关闭」。
- 输出：`primary`（紧凑位）、`secondary`（小圆泡）、`queued`（排队）。纯函数，放在 `Island.Core`，单元测试覆盖。
- 卫星岛（08 §4）不再是独立机制：消息通知成为一次**提醒**，未读数成为一个 `passive` 活动（因此会进小圆泡）。

### 2.2 交互（Mac / Windows / Linux，鼠标）

| 操作 | 结果 |
| --- | --- |
| 指针移上岛 | 岛轻微放大（预告），不展开 |
| 单击岛 | 有活动：展开当前活动；没有：进入主页 |
| ⌘ / Ctrl + 单击，或双击 | 打开活动的来源应用（活动声明了 `open` 时） |
| 单击小圆泡 | 它和紧凑位的活动互换 |
| 在岛上横向滚动 | 在活动之间切换；向上滚动把当前活动暂时收起（排到队尾） |
| 指针离开一会儿 | 收回 |
| 右键 | 菜单（外观、主页、设置……）不变 |

### 2.3 动画

- 岛的外形是**一个形状**：宽、高、圆角用同一个弹簧做连续变形；小圆泡从岛边缘分离、消失时吸回。
- 内容切换带模糊淡入；数字用滚动过渡。
- 弹簧参数来自主题的动效层（§4）；「减少动态效果」开启时改为淡入淡出。

## 3. 插件 API 2.0

清单 `engines.island` 必须是 `^2.0.0`；宿主拒绝 1.x 的插件并说明原因。旧的 `island.chip`、`island.page`、
`island.satellite`、自由绘制整块界面的活动视图全部移除。

```js
import { island, ui } from '@island/api';

// 活动：有开始和结束。宿主决定它在紧凑位、小圆泡还是排队。
const playing = island.activity('playing', {
  priority: 'normal',
  accent: 'music',                       // 强调色的语义名，颜色由主题给
  open: { app: 'com.netease.163music' }, // ⌘ 单击时打开
  compact:  { leading: ui.icon('Music'), trailing: ui.spectrum({ bars: 5 }) },
  minimal:  ui.icon('Music'),
  expanded: {
    leading:  ui.image(cover),
    center:   ui.title('晴天', { subtitle: '周杰伦' }),
    trailing: ui.spectrum({ bars: 9 }),
    bottom:   ui.stack([ui.progress(0.27), ui.controls([...])]),
  },
});
playing.update({ ... });   // 同样的结构，局部更新
playing.alert({ ... });    // 让岛短暂展开
playing.end();

// 环境项：空闲时显示的一小块（天气、时间、吉祥物）。只有 leading 或 trailing 一个区域。
island.ambient('temp', { side: 'left', view: ui.row([ui.icon('Sun'), ui.text('17°')]) });

// 主页的一页：仍然由 ui.* 组件拼成，但只出现在主页里。
island.home.page('today', { title: '日历', view: ... });

// 一次性提醒（没有对应的活动）。
island.alert({ leading: ui.appIcon(app), center: ui.title('测试', { subtitle: '发来新消息' }), seconds: 4 });
```

- 区域里的内容仍由 `ui.*` 组件拼成，但每个区域有尺寸上限（紧凑区只有一行、有最大宽度），超出由宿主裁切或省略。
- 清单：`contributes.activities`、`contributes.ambient`、`contributes.home`（取代 `chips`、`pages`、`satellites`）。
- 权限、设置、数据来源（providers）、通知监听不变。

## 4. 主题包

主题是 `contributes.themes` 里的一个包；宿主渲染，主题不运行代码。

```text
com.example.theme.neon/
  plugin.json
  theme.json          分层配置（见下）
  background.*        动态背景（可选）
  mascot/             吉祥物素材（可选）
  sounds/             提示音（可选）
  templates/          区域版式模板（可选）
```

```jsonc
{
  "surface": { "material": "glass", "tint": "#101018", "blur": 24, "background": "background.lottie" },
  "shape":   { "radius": 22, "bubble": "circle", "split": "droplet" },
  "content": { "foreground": "#FFFFFF", "secondary": "#9A9AA5", "font": "rounded", "iconStyle": "filled",
               "accent": { "default": "#7C5CFF", "music": "#FF4D6D", "timer": "#FF9F0A", "message": "#30D158" } },
  "motion":  { "spring": "bouncy", "reduce": "fade" },
  "mascot":  "mascot/",
  "sounds":  { "alert": "sounds/alert.wav" },
  "templates": { "compact": "templates/compact.json", "expanded": "templates/expanded.json" }
}
```

| 层 | 能改什么 |
| --- | --- |
| 表面 | 材质（纯黑、玻璃、渐变、图片、动态背景）、色调、模糊 |
| 形状 | 圆角、小圆泡的样子、分离方式 |
| 内容 | 前景 / 次要色、字体、图标风格、每类活动的强调色 |
| 动效 | 弹簧预设、减少动态效果时的替代 |
| 素材 | 吉祥物、提示音 |
| 版式 | 紧凑、最小、展开各区域的排布（声明式：区域的位置、对齐、间距；不能放任意内容） |

**约束（宿主强制）**

- 贴着真实刘海时表面强制为黑色，动态背景只画在刘海以外的部分。
- 动态背景有帧率和尺寸上限；用电池、低电量模式或全屏应用在前时自动降为静态图。
- 主题校验失败（缺文件、颜色对比度不够、模板越界）时回退到默认主题，并在外观页说明原因。
- 提示音默认关闭，由用户在外观页打开。

**风险**：Lottie / 视频背景需要一个兼容 AOT 裁剪的渲染库，要先做技术验证；验证通过前先支持渐变、图片和着色器动画。

## 5. 控制台

**岛体页**（左右分栏，右侧是真实内容预览）

- 活动：优先级排序；每类活动设为 允许 / 只提醒 / 关闭；固定。
- 空闲时：环境项（每侧最多 2 个，可拖动排序、换边、全部关闭）。
- 主页：页签顺序、开关、首页。
- 外观：形态、停靠、大小、全屏时。
- 预览：空闲、紧凑、最小、展开、主页，用插件当前的真实内容；「在岛上试一下」。

**外观页**：主题画廊（每个主题用真实内容渲染一个小岛）、主题的可调项、提示音开关。

## 6. 分阶段实施

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| 0 | 提交工作区里未完成的改动（插件市场、网易云暂停修复） | 干净的起点 |
| 1 | 状态模型和仲裁（`Island.Core`，纯逻辑 + 测试） | 可测试的核心，不改界面 |
| 2 | 插件 API 2.0：运行时、清单校验、区域模型 | 新 API 可用，旧插件被拒绝 |
| 3 | 岛的渲染：单形状变形、小圆泡、区域模板、新交互 | 新的岛 |
| 4 | 主题引擎：分层配置 → 素材 → 版式模板；动态背景先做技术验证 | 主题包 |
| 5 | 重写官方插件（内置 17 个、目录 13 个）；目录下架旧版本 | 全部插件迁移 |
| 6 | 控制台：岛体页、外观页、预览 | 设置和预览 |
| 7 | 文档（03、05、07、08 更新）、插件开发技能更新、发布 0.2.0 | 发布 |

阶段 1、2 完成前岛保持 1.x 的行为；阶段 3 起在开发分支上切换，全部插件迁移完再合并发布。
