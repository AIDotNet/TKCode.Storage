# 07 · 首页、收起内容与岛体配置

> 状态：已讨论定稿（2026-11-10）；第 1–4 步均已实现。参考：岛仔 Daozai（顶部 / 左 / 右三边停靠、刘海 / 胶囊两种形态、页面开关与排序、收起时的一排小项）。

## 1. 已定决策

| 问题 | 结论 |
| --- | --- |
| 展开后的导航 | **标签式**：标题行是一排页面文字标签（`TextTabs`）；页内的二级切换（如 AI 用量的提供商）用卡片两侧的 ‹ › 与底部圆点 |
| 点开岛时显示哪页 | **智能**：有正在进行的活动（播放中、专注计时、会议将开始等）就打开该活动所属的页；否则打开用户设定的首页 |
| 默认形态 | **胶囊**。刘海屏 Mac 停靠顶部时，胶囊罩住刘海、比刘海宽，内容避开刘海显示在两侧（2026-11-09 修订：原为悬浮在菜单栏下方，会挡住窗口标签页）；用户可把形态改为"刘海"（贴边、带肩部） |
| 收起时显示 | **用户选择的一排小项**（时间、电量、AI 账户小圆环、音乐律动……），可开关、排序；有提醒时临时让位 |

## 2. 概念

三个概念取代目前"活动兼任一切"的做法：

| 概念 | 是什么 | 谁提供 | 显示在哪 |
| --- | --- | --- | --- |
| **页面（Page）** | 一个功能的完整视图：AI 用量、音乐、待办、专注、日程…… | 插件在清单里声明 `contributes.pages`，用 `island.page(id).update(view)` 渲染 | 展开后的岛，标题行一页一个标签 |
| **小项（Chip）** | 收起时的一个小部件：时间、电量、某个 AI 账户的小圆环、律动条…… | 插件声明 `contributes.chips`，用 `island.chip(id).update(view)` 渲染 | 收起的岛，一排；刘海形态下分在左右两翼 |
| **活动（Activity）** | 临时的"正在发生"：播放中、专注计时中、会议 5 分钟后开始、额度告警 | 插件运行时 `island.activity.create(id, { page, priority })` | 收起时可临时占据小项位置（提醒）；点开岛时把用户带到它的 `page` |

时间不再需要一个页面：展开后的标题行常驻日期与时间（刘海形态时放在右翼）。现在的"时钟"插件改为提供 **时间小项** 和可选的 **"今日"页**（日期、秒表、下一个日程），默认不启用"今日"页。

## 3. 展开后的布局

```text
╭────────────────────────────────────────────────────────╮
│ ◉  AI 用量  音乐  待办  ⌄更多        11月10日 周二 11:31 ⋯ │  ← 页面标签 · 日期时间 · 菜单
│                                                        │
│ ‹      ◯41%   ◯13%      Max 20x                      ›  │  ← 当前页的内容（页内 ‹ › 与圆点是页自己的）
│                         ● ○                            │
╰────────────────────────────────────────────────────────╯
```

- 标签放不下时，只显示能放下的，其余收进末尾的"更多 ⌄"文字选择器（`picker`）。刘海形态下标题行只有左翼可用，同样处理。
- 当前页标签白色半粗，其余灰色；有新内容的页标签旁一个强调色小圆点。
- 全部遵守 02 §7 的岛内设计要求。

### 3.1 智能首页

点开岛（悬停或点击展开）时按顺序决定显示哪页：

1. 用户上一次是**主动**切到某页、且距今不到 30 秒（来回移动指针造成的收起再展开）→ 留在该页；
2. 有优先级为 `active` 或 `critical` 的活动，且它声明了 `page` → 打开该页（多个时取优先级最高、最近开始的）；
3. 否则打开用户设定的**首页**（默认是第一个启用的页面）。

## 4. 收起时的小项

```text
胶囊：   ╭─ ◔76  09:41  ⓒ41%  ⓧ0%  ▮▮▯▮ ─╮
刘海：   ◔76  09:41  ⓒ41% ▓▓▓▓刘海▓▓▓▓ ⓧ0%  ▮▮▯▮      ← 每个小项可选放在左翼或右翼
```

- 小项由插件渲染，宽度上限 64pt（极简模式下只显示时间）。超出岛宽时从末尾开始隐藏。
- 提醒（`Alert` 状态，如"已复制""专注结束""额度 95%"）临时替换小项区域几秒，然后恢复。
- 用户在设置里勾选、拖动排序；刘海形态下另可为每个小项选择左翼 / 右翼。

## 5. 形态与停靠

| 设置 | 选项 | 说明 |
| --- | --- | --- |
| 形态 | **胶囊**（默认）/ 刘海 | 胶囊：四角连续圆角、悬浮；刘海：贴住停靠的那条屏幕边，带内凹肩部 |
| 停靠 | **顶部**（默认）/ 左侧 / 右侧 | 侧边停靠时收起为**竖向胶囊**（小项竖排，最多 4 个），展开时面板从屏幕边缘滑出，内容与顶部停靠相同 |
| 大小 | 80%–140% | 按比例缩放 `IslandMetrics`（尺寸、圆角、字号随 Arc token 不变，岛内留白按比例） |
| 位置 | 沿停靠边的偏移 | 顶部可左右移、侧边可上下移；拖动岛本身也能直接调整（按住 ⌥ 拖动）。**已实现**（2026-11-10）：按住 ⌥（Windows / Linux 为 Alt）拖动岛，沿停靠边实时移动，松开后保存；限制在屏幕内；包住刘海时不能拖动 |
| 显示器 | 主屏 / 跟随鼠标 / 指定屏 | 沿用 02 §4。**已实现**主屏（默认）、跟随鼠标（指针移到另一块屏时岛随之移动，展开时不动）、指定屏（"岛体"页列出当前屏幕；按"显示器名称 + 像素尺寸"识别，换了排列位置仍能找到；名字或尺寸之一变了且不产生歧义也能找到；那块屏不在时显示在主屏，接回后自动回去） |
| 全屏时 | 隐藏 / 收成贴边细线 | 指定应用（或任何全屏应用）覆盖时。**已实现**隐藏（默认，淡出且完全点击穿透）/ 细线 / 显示；检测：macOS 窗口列表中最前的普通窗口占满整屏，Windows 前台窗口占满所在显示器，Linux 活动窗口带 `_NET_WM_STATE_FULLSCREEN`。细线：静止时缩成贴边的 4pt 细胶囊（顶部 120×4、侧边 4×72），不显示小项，指针推到屏幕边即可展开；包住刘海时静止形态仍是刘海本身。按应用指定待做 |
| 极简模式 | 开 / 关 | 收起时只显示时间与提醒。**已实现**：开启后收起的岛只显示 O_O 自己的时间（HH:mm，每分钟更新），提醒和 active/critical 活动照常临时占位；"收起时显示"的设置保留 |

与刘海的关系：

| 屏幕 | 停靠顶部 + 胶囊 | 停靠顶部 + 刘海 |
| --- | --- | --- |
| 有刘海的 Mac | 罩住刘海的胶囊：四角圆角、无肩部，静止时也比刘海宽一圈，小项分在两翼 | 包住刘海（02 §3.2，带肩部，静止时与刘海同宽） |
| 无刘海的屏幕 | 悬浮在顶边下方 | 贴住顶边、带肩部 |

`IslandLayout` 需要扩展：停靠边（上 / 左 / 右）、缩放、偏移，以及侧边的竖向收起尺寸；刘海检测与包裹逻辑保持不变。

## 6. 设置界面（控制台新增"岛体"页）

全部在控制台（岛外，可以用 Arc 的完整组件）：

| 区块 | 内容 | Arc 组件 |
| --- | --- | --- |
| 外观 | 形态、停靠、大小、位置、显示器、极简模式、全屏时 | `SegmentedControl`、`Slider`、`Select`、`Switch` |
| 页面 | 所有插件声明的页面：开关、拖动排序、"设为首页" | `ReorderableList` + `Switch` + 行内文字按钮 |
| 收起时显示 | 所有小项：开关、排序；刘海形态下选择左翼 / 右翼 | `ReorderableList` + `Switch` + `SegmentedControl` |
| 预览 | 当前设置下的岛（收起与展开） | 复用 `IslandSnapshot` 的离屏渲染，实时更新 |

关闭某页或某个小项**不会停用插件、也不会删除数据**；插件的停用仍在"插件"页。

## 7. 插件接口变化

```jsonc
// plugin.json
"contributes": {
  "pages": [{ "id": "usage", "title": "AI 用量", "icon": "Gauge" }],
  "chips": [{ "id": "account", "title": "AI 账户小圆环", "multiple": true }]   // multiple：一个插件可产生多个同类小项（每个账户一个）
}
```

```js
island.page('usage').update(view);                 // 展开视图
island.chip('account', 'claude:work').update(view); // 收起小项（第二个参数区分 multiple 的实例）
island.activity.create('playing', { page: 'now', priority: 'active' });
```

现有的 `activity.update({ compact, expanded })` 保留一段时间作为兼容：`expanded` 映射为同名页面，`compact` 映射为临时小项。

## 8. 分步实现

1. **岛体布局** ✅：`IslandAppearance`（形态、停靠、大小、偏移，存于 `<数据目录>/island.json`）；`IslandLayout.Compute(..., offset, scale)` 在岛的单位里排版、窗口按比例放大；包住刘海时大小与偏移不生效；控制台"岛体"页（形态、停靠——左右暂不可选、大小、水平位置）；默认胶囊。显示器、全屏时、极简模式、⌥ 拖动和预览留到后续步骤。
2. **页面与智能首页** ✅：`contributes.pages`（`title`、`icon`、`enabled` 默认开关）与 `island.page(id).update(view)`；活动可声明 `page`；标题行页面标签 + 放不下时的"更多 ⌄"、右侧日期时间；`SmartHome` 规则（30 秒内手动选的页 → active/critical 活动的页 → 首页）；页面设置存于 `pages.json`，控制台"岛体"页新增"页面"区块（拖动排序、开关、设为首页）。时钟改为收起时显示时间 + 默认关闭的"今日"页；AI 用量改为常驻页面，超过提醒阈值时活动升为 active。旧的 `activity.update({ expanded })` 仍作为临时页面显示。
3. **小项** ✅：`contributes.chips`（`title`、`multiple`、`enabled`、`side`）与 `island.chip(id[, instance]).update(view, { title })` / `.remove()`；`island.alert({ leading, trailing }, { seconds })`（1–10 秒，默认 3）。收起时按左 / 右两组显示（胶囊两端、刘海两翼），每侧最多 3 个、每个最宽 64pt，岛宽随内容变化；优先级：提醒 → 带收起视图的 active/critical 活动 → 小项；旧活动的 `compact` 作为临时小项。设置存于 `chips.json`，控制台"岛体"页新增"收起时显示"（排序、开关、左 / 右；`multiple` 小项列出当前出现的实例）。时钟提供"吉祥物"（左）与"时间"（右）小项；AI 用量提供"最高用量"小项与默认关闭的每账户小项，超过阈值时提醒一次。极简模式留待以后。
4. **侧边停靠** ✅：`IslandLayout.Compute(screen, placement, dock, state, metrics, offset, scale)` / `ComputeSide`。岛贴左 / 右边、在菜单栏以下的高度上居中，偏移改为上下移动；窗口在侧边竖放（460×760）。收起为竖向胶囊（两组小项上下排列，每组最多 2 个、共 4 个，宽高随内容）；展开为**抽屉**：380pt 宽、高随内容（最高 600pt），以胶囊为中心从边缘长出，始终留在屏幕内（2026-11-09 修订：原为与顶部相同的 640pt 宽卡片，从细胶囊横向铺开不合理）。胶囊形态离边 8pt，刘海形态紧贴边缘、贴边一侧为直角、无肩部；胶囊与屏幕边之间的窄条也算悬停区域，指针推到屏幕边即可唤出。侧边不受刘海影响，大小可调。

每步完成后都可单独使用；第 4 步工作量最大，放在最后。
